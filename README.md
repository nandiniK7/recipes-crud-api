# Recipes CRUD API

Backend Deployed URL:
https://recipes-crud-api-1.onrender.com

Postman Documentation:
https://documenter.getpostman.com/view/51232224/2sBXqQEH9n

Features:
- Create Recipe
- Get All Recipes
- Get Recipe By ID
- Update Recipe
- Delete Recipe

Tech Stack:
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Render
- Postman
